本文档服务 Phase 4：输入 `问题材料`、`解释材料`，输出 `第二轮状态`、`路由结果`、`诊断材料`。

## 1. 判定变量

```text
概念定义模糊 = 概念定义 显示一个核心概念没有稳定定义
逻辑冲突 = 非 概念定义模糊 且 概念关系 把不同层级对象直接连成因果关系
```

## 2. 决策顺序

```text
如果 概念定义模糊:
  第二轮状态 = 已定位诊断模块
  路由结果 = Phase 6
  诊断类型 = 概念定义模糊，陷进了文字游戏
  认知路径 = 离线认知活动，构建相关的认知体系
  诊断依据 = 用户对核心概念没有稳定定义，当前材料不支持继续判断概念之间的逻辑关系
  最小工具 = DeepSeek、豆包、元宝等
  最小动作 = 打开上面提到的任何AI工具，让AI来给一份跟你不一样的概念定义和理解视角

否则如果 逻辑冲突:
  第二轮状态 = 已定位诊断模块
  路由结果 = Phase 6
  诊断类型 = 逻辑冲突，没分清楚因果和层次关系，把不相关的事情联系到一起
  认知路径 = 离线认知活动，构建相关的认知体系
  诊断依据 = 概念关系把不同层级对象直接连成因果关系
  最小工具 = DeepSeek、豆包、元宝等
  最小动作 = 打开上面提到的任何AI工具，让AI来给一份逻辑关系分析

否则:
  第二轮状态 = 已定位诊断模块
  路由结果 = Phase 6
  诊断类型 = 整个思考模型和解释框架不匹配事实
  认知路径 = 离线认知+在线认知活动，构建相关的双重认知体系
  诊断依据 = 概念定义已稳定，概念关系未显示直接逻辑冲突，但这套解释不能解释问题材料中的现实冲突
  最小工具 = DeepSeek、豆包、元宝等
  最小动作 = 把“我之前以为...”和“但是现在遇到了...”之间的冲突写成一句可检查关系，并做一次现实反馈验证

```

## 3.输出字段
 
```text
诊断材料:
  诊断类型:
  诊断依据:
  认知路径:
  最小工具:
  最小动作:
```
