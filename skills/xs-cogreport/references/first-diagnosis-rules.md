本文档服务 Phase 2：输入 `问题状态`、`问题材料`，输出 `第一轮状态`、`路由结果`、`报告模板`。

## 1. 判定变量

```text
描述不清 = 问题状态 是 描述不清
主要卡点 = 用户当前最需要解决才能继续判断、选择、表达或行动的卡住原因
认知判断 = 主要卡点 是无法理解、无法判断、无法解释或无法表达
非认知判断 = 主要卡点 是资源限制、权限不足、体力不够、熟练度不够、其他外部条件限制、执行意愿不够、目标偏好、信息查询或任务代办
```

## 2. 决策顺序

```text
如果 描述不清:
  第一轮状态 = 不支持诊断器判断
  路由结果 = 停止 skill
  报告模板 = 描述不清报告

否则如果 认知判断:
  第一轮状态 = 需要补充解释
  路由结果 = 停止 skill
  报告模板 = 第一轮需补充解释报告

否则:
  第一轮状态 = 不支持认知问题判断
  路由结果 = 停止 skill
  报告模板 = 非认知问题报告

```
