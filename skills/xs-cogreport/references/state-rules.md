本文档服务 Phase A：输入 `对话上下文`，输出 `入口阶段`、`路由结果`。

## 1. 判定变量

```text
固定问题首句 = 对话上下文中上一条 xs-cogreport 输出包含的固定问题首句
```

## 2. 决策顺序

```text
如果 固定问题首句 = "请回答这两个问题：":
  入口阶段 = Phase 1
  路由结果 = Phase 1

否则如果 固定问题首句 = "请补充一下你对自己说出的话的理解：":
  入口阶段 = Phase 3
  路由结果 = Phase 3

否则:
  入口阶段 = Phase 0
  路由结果 = Phase 0
```
