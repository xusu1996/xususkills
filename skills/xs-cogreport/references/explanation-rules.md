本文档服务 Phase 3：输入 `用户消息`、`对话上下文`、`上轮解释材料`、`本轮解释输入`，输出 `解释状态`、`路由结果`、`解释材料`。

## 1. 判定变量

```text
解释材料 = 上轮解释材料 与 本轮解释输入合并后的结果
核心概念 = 解释材料中用户明说的核心概念
概念定义 = 解释材料中用户明说的概念定义或具体意思
概念关系 = 解释材料中用户明说的概念之间关系
说不清 = 用户整体表示说不清、搞不懂或不知道
条件1 = 核心概念 存在
条件2 = 概念定义 存在
条件3 = 概念关系 存在
```

## 2. 决策顺序

```text

如果 说不清:
  解释状态 = 无解释材料
  路由结果 = Phase 6
  解释材料完整度 = 无

否则如果 条件1 且 条件2 且 条件3:
  解释状态 = 解释材料完整
  路由结果 = Phase 4
  解释材料完整度 = 完整

否则:
  解释状态 = 解释材料不完整
  路由结果 = Phase 6
  解释材料完整度 = 部分
```

## 3. 输出字段

```text
解释材料:
  核心概念:
  概念定义:
  概念关系:
  解释材料完整度: 完整 / 部分 / 无
```
