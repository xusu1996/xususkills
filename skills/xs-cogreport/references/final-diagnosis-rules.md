本文档服务 Phase 6：输入 `解释材料`、`Phase 4 诊断材料`，输出 `最终状态`、`路由结果`、`报告模板`、`诊断材料`。

## 1. 判定变量

```text
彻底说不清入口 = 解释材料.解释材料完整度 = 无
部分解释材料入口 = 解释材料.解释材料完整度 = 部分
完整解释材料入口 = Phase 4 诊断材料.诊断类型 存在
```

## 2. 决策顺序

```text
如果 彻底说不清入口:
  最终状态 = 已诊断
  路由结果 = 停止 skill
  报告模板 = 彻底说不清报告
  诊断类型 = 概念混淆，逻辑关系混乱，语言解释能力完全缺失
  诊断来源 = Phase 3 无解释材料
  诊断依据 = 用户无法提供核心概念、概念定义和概念关系，当前材料显示其语言解释系统无法形成最低限度解释材料
  认知路径 = 离线认知活动 + 在线认知活动
  最小工具 = DeepSeek、豆包、元宝等
  最小动作 = 先用AI工具尝试一句话梳理清楚自己的认知困境，然后再次找我做诊断

否则如果 部分解释材料入口:
  最终状态 = 已诊断
  路由结果 = 停止 skill
  报告模板 = 部分说得清报告
  诊断类型 = 理解比较模糊、概念定义错误、逻辑关系混乱
  诊断来源 = Phase 3 部分解释材料
  诊断依据 = 用户提供了部分核心概念、概念定义或概念关系，但没有形成完整解释材料
  认知路径 = 离线认知活动
  最小工具 = DeepSeek、豆包、元宝等
  最小动作 = 补齐本问题中的核心概念、概念定义和概念关系

否则如果 完整解释材料入口:
  最终状态 = 已诊断
  路由结果 = 停止 skill
  报告模板 = 完整解释材料报告
  诊断来源 = Phase 4 第二轮诊断
  使用 Phase 4 诊断材料.诊断类型、Phase 4 诊断材料.认知路径、Phase 4 诊断材料.诊断依据、Phase 4 诊断材料.最小工具、Phase 4 诊断材料.最小动作

否则:
  最终状态 = 规则失效
  路由结果 = 停止 skill
  报告模板 = 无
  诊断材料 = 无
  失败条件 = Phase 6 没有收到解释材料完整度为无、解释材料完整度为部分或 Phase 4 诊断材料
```

## 3. 输出字段

```text
报告模板: 彻底说不清报告 / 部分说得清报告 / 完整解释材料报告 / 无

诊断材料:
  诊断类型: 
  诊断来源:
  诊断依据:
  认知路径: 
  最小工具:
  最小动作:
```
