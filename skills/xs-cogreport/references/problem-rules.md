本文档服务 Phase 1：输入 `用户消息`、`对话上下文`、`上轮问题材料`、`本轮问题输入`，输出 `问题状态`、`路由结果`、`问题材料`、`回复模板`。

## 1. 判定变量

```text
问题材料 = 上轮问题材料 与 本轮问题输入合并后的结果
具体情况 = 问题材料中用户明说或用户改写的具体情况
困惑点 = 问题材料中用户明说或用户改写的想不明白之处
描述不清 = 用户回复“我描述不清”

条件1 = 具体情况 存在
条件2 = 困惑点 存在
条件3 = 描述不清 存在
```

## 2. 决策顺序

```text
如果 条件3:
  问题状态 = 描述不清
  路由结果 = Phase 2
  回复模板 = 无

否则如果 条件1 且 条件2:
  问题状态 = 完整
  路由结果 = Phase 2
  回复模板 = 无

否则:
  问题状态 = 不完整
  路由结果 = 停止 skill
  回复模板 = 询问问题叙述
```

## 3. 输出字段

```text
问题材料:
  用户问题原文:
  具体情况:
  困惑点:
```

## 4. 询问问题叙述

```text
请回答这两个问题：

1. 你觉得自己是否能描述清楚遇到了什么问题，如果能，可以尝试用这个句式重新描述一下：我之前以为...但是现在遇到了「现实情况」，我想不通「某个问题」。
2. 如果描述不清，请回复：我描述不清。
```
